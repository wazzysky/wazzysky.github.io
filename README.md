# WazzySky 的项目 List

机器人、嵌入式系统、三维感知与具身智能相关项目展示站。

在线访问：**[wazzysky.github.io](https://wazzysky.github.io)**

## 项目概览

| # | 项目 | 类型 | 关键词 |
|---|------|------|--------|
| 1 | 三维点云语义切割算法复现 | 科研 | Python, PyTorch, CENet, Pointcept, DBSCAN |
| 2 | 自主导航与 LLM 交互机制调研 | 科研 | LLM, Zero-shot Navigation, CLIP, Scene Graph |
| 3 | RoboCup SSL 局部视觉重构 | 比赛 | C++, OpenCV, libcamera, Raspberry Pi |
| 4 | RoboCup SSL 系统架构重构 | 比赛 | ESP32, FreeRTOS, UDP, Protobuf, SPI |
| 5 | 树莓派智能垃圾桶系统 | 作业 | Pi + STM32, YOLO, ONNX, PID |

## 技术栈

C++ · Python · OpenCV · PyTorch · FreeRTOS · ESP32 · STM32 · Raspberry Pi · YOLO · ONNX · CLIP · PCL

## 本地运行

```bash
bundle exec jekyll serve
```

浏览器打开 `http://localhost:4000`。
